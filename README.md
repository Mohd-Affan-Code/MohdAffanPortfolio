# 🌐 Personal Portfolio Website | व्यक्तिगत पोर्टफोलियो वेबसाइट

A clean, responsive, and multilingual **React + Tailwind CSS Portfolio Website** showcasing my projects, skills, and experience.  
यह एक आधुनिक और रिस्पॉन्सिव **React + Tailwind CSS पोर्टफोलियो वेबसाइट** है, जो मेरे प्रोजेक्ट्स, स्किल्स और अनुभव को दर्शाती है।

---

## ✨ Features | विशेषताएँ

- 🎨 **Modern & Minimal UI** – Built with Tailwind CSS for a clean and professional look.  
  **आधुनिक और साफ-सुथरा डिजाइन**, Tailwind CSS से बनाया गया।

- 🌗 **Light / Dark Mode** – Toggle between light and dark themes.  
  **लाइट और डार्क मोड** के बीच आसानी से स्विच करें।

- 🌍 **Multilingual Support (English/Hindi)** – Integrated with `i18next` for language switching.  
  **बहुभाषी सपोर्ट** – `i18next` के साथ अंग्रेजी और हिंदी दोनों भाषाओं में उपलब्ध।

- 💼 **Projects Section** – Showcases my major React projects.  
  **प्रोजेक्ट्स सेक्शन** – मेरे प्रमुख React प्रोजेक्ट्स को प्रदर्शित करता है।

- 📱 **Fully Responsive Design** – Looks perfect on desktop, tablet, and mobile.  
  **पूरी तरह रिस्पॉन्सिव डिजाइन**, जो हर डिवाइस पर शानदार दिखती है।

- 🧭 **Smooth Navigation** – Fast transitions and scroll animations.  
  **स्मूद नेविगेशन** और **सुंदर स्क्रॉल एनीमेशन।**

---

## 🛠️ Tech Stack | टेक्नोलॉजी स्टैक

- ⚛️ **React.js** – Frontend Library
- 🎨 **Tailwind CSS** – Styling Framework
- 🌐 **i18next** – Multilingual Setup (English & Hindi)
- 💬 **Framer Motion** – Smooth Animations
- ☁️ **Vercel / Netlify** – Deployment
